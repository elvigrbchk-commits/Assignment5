# JavaScript Basics — DOM Manipulation & Events

## Description
This project demonstrates the fundamentals of JavaScript, including DOM manipulation, event handling, and interactive web elements. It consists of four parts developed using HTML, CSS, JavaScript, and Bootstrap 5.

## Project Structure

- `index.html` — Introduction to JavaScript: variables, operators, and basic scripts.
- `script.js` — JavaScript basics.
- `Part 2 - DOM.html` — DOM manipulation: changing text, styles, and list elements.
- `Part 2 - DOM.js` — DOM manipulation functionality.
- `Part 3 - Events.html` — Mouse events, keyboard events, and calculator.
- `Part 3 - Events.css` — Styles for the events section.
- `Part 3 - Events.js` — Event handling and calculator logic.
- `Part 4 - To-Do List.html` — Interactive task management interface.
- `Part 4 - To-Do List.js` — To-Do List functionality.

## Features

- Basic JavaScript variables and arithmetic operations.
- Dynamic content and style changes using the DOM.
- Adding and removing list items.
- Mouse and keyboard event handling.
- A calculator supporting addition, subtraction, multiplication, and division.
- An interactive To-Do List with task management.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5


## Purpose

The purpose of this assignment is to practice JavaScript fundamentals, DOM manipulation, and event handling through practical web development tasks.
